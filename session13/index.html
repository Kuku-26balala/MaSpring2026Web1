PEKING OPERA

FINAL WEBSITE PROPOSAL

THEME
This project explores the art and cultural significance of Peking Opera, one of the most iconic forms of traditional Chinese performance. The website aims to introduce its history, visual aesthetics, symbolic makeup, and theatrical traditions through an immersive digital experience.
WEBSITE DESCRIPTION
The website will consist of three main sections. The first page will provide an introduction to the history and origins of Peking Opera. The second page will focus on traditional character roles, including Sheng, Dan, Jing, and Chou, along with the meanings behind facial makeup and costume design. The final page will feature interactive elements that allow users to explore masks, symbolism, and visual details through animation and user interaction.
FONTS & COLORS
I want the website to have a traditional and theatrical feeling. I plan to use serif or brush-style fonts inspired by Chinese opera aesthetics. The main colors will be red, black, and gold because they reflect traditional Chinese culture and create a dramatic visual atmosphere.
INTERACTIVE ELEMENTS (JavaScript, p5.js & jQuery)

JavaScript element:

Add interactive buttons and image effects. Users can hover over Peking Opera masks to see information, or click images to reveal hidden content.


p5.js element:

An interactive “mask changing” animation inspired by Peking Opera. Users can click or move the mouse to switch between different opera masks (different colors and facial expressions). The animation reacts to user interaction and creates a simple “face-changing” effect.


jQuery element:

Use effects like slideToggle(), fadeIn(), and animations. Buttons let users show and hide different sections smoothly.
